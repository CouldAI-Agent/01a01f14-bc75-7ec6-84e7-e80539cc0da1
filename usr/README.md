# News Website

A responsive news website application built with Flutter. It adapts gracefully to mobile, tablet, and desktop viewports to deliver a clean reading experience.

## Features
- Responsive layout (mobile list view vs desktop grid view).
- Article models and mocked news data.
- Modern Material 3 UI design.
- Category navigation.

## Tech Stack
- Flutter
- Dart
- Material 3

## Setup & Run
To run this project:
1. Ensure Flutter is installed and configured.
2. Run `flutter pub get` to fetch dependencies.
3. Run `flutter run -d chrome` to run as a web app.
